# openMMD Web

Браузерный редактор использует общий Rust-код форматов, анимации и рендера.
WASM собирается вместе с сайтом GitHub Pages; приложение доступно по `/openMMD/app/`.
Нужен браузер с WebGPU и аппаратным ускорением, HTTPS или localhost.

Кнопка **Open local files** позволяет выбрать несколько файлов одновременно:
модель PMD/PMX, её diffuse-текстуры, VMD/VPD и при необходимости PMM вместе
со всеми его моделями. Можно сначала выбрать PMM, затем добавить недостающие
ресурсы. Неоднозначные имена файлов отклоняются. Процедурный demo rig не
содержит моделей из оригинального дистрибутива.

Файлы обрабатываются в памяти текущей вкладки, на сервер не отправляются.
После перезагрузки страницы их нужно выбрать снова. Для японских имён можно
добавить локальный TTF/OTF/TTC-шрифт. Неверные файлы шрифтов отклоняются.
Ограничение импорта: 128 MiB на файл и 256 MiB ресурсов на вкладку.

Есть playback, видимость и переключатели IK из VMD, базовый IK, редактирование костных/морф-ключей, Undo/Redo,
импорт/экспорт VMD/VPD и сохранение анимационных правок существующего PMM.
Веб-версия воспроизводит PMM- и VMD-камеру/свет. VMD камеры можно открыть без
модели, а её экспорт доступен через Export scene VMD. Редактирование PMM-камеры/света, расширенные
операции ключей и кривые пока доступны только в desktop-интерфейсе.
Кнопки экспорта скачивают результат через браузер. Перед экспортом анимации
зарегистрируйте изменения позы кнопкой Register.

Экспорт PMM сохраняет исходные ссылки на модели; сами модели/текстуры в PMM не
упаковываются. При следующем открытии выберите ресурсы снова. Ограничения
PMX, физики, аксессуаров и точности воспроизведения совпадают с общими
ограничениями проекта. Веб-версия также остаётся неполной реализацией MMD.

## Сборка

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.128 --locked
sh scripts/build_web.sh
python3 -m http.server 8765 --directory site
```

Откройте `http://localhost:8765/app/`. Бинарные WASM/JS в `site/app/pkg`
генерируются скриптом и не хранятся в Git. Workflow `pages.yml` собирает их
перед публикацией. Настройка браузера не требует Cross-Origin Isolation:
используется обычная однопоточная WASM-сборка.

`start`, `import_files`, `load_demo`, `web_status` экспортируются в JS и
доступны через `window.openMMD` после старта. Последняя функция возвращает JSON
со счётчиками моделей/вершин/ресурсов, кадром и статусом для воспроизводимой QA.

Подробности сохранности дополнительных дорожек и ограничений импорта в PMM: [VMD](vmd.md).

## Узкие экраны

При ширине редактора меньше 700 CSS-пикселей боковая панель заменяется кнопкой
**Inspector**: она открывает прокручиваемое окно поверх сцены. Импорт остаётся
в верхней панели, демо и экспорт находятся в меню **Tools**. Кнопки и элементы
управления увеличены для касания; строка воспроизведения переносится, а сцена
занимает оставшееся пространство. Drag одним пальцем вращает камеру; pinch
двумя пальцами меняет масштаб. Поворот устройства меняет раскладку автоматически.
Это адаптивный интерфейс; доступность WebGPU зависит от браузера и устройства.
