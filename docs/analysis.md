# Дистрибутив и границы исследования

Объект: https://learnmmd.com/MikuMikuDanceE_v932x64.zip

SHA-256: `92c043f3e136f474ab407c198aaaec3e3f81fb02983da3802f169e9f78e1324a`.

Подтверждено локальным чтением ZIP и `file`: PE32+ Windows x86-64 executable,
readme MikuMikuDance 9.32 English, PMD-модели, три PMM-примера, DirectX X
аксессуары, toon BMP, sphere textures и VPD-позы. Исходники в архиве не обнаружены.
Оригинальное EXE не запускалось; эквивалентность поведения и визуальное совпадение
с MMD не проверены. В поставляемом readme указаны Visual C++ 2008/2010 и DirectX.

REA MCP-инструменты в сессии отсутствуют. Попытка read-only doctor через npx
не завершилась из-за недоступного registry.npmjs.org в сетевой песочнице.
Архив анализировался штатными ZIP-инструментами; дизассемблирование не выполнялось.
Дальнейшая разработка — самостоятельная реализация, а не декомпиляция EXE.

Бинарную структуру PMM сверяли с открытой реализацией nanoem:
https://github.com/hkrn/nanoem/blob/main/nanoem/ext/document.c

Структуру PMX сверяли с:
https://github.com/MMD-Blender/blender_mmd_tools/blob/main/mmd_tools/core/pmx/__init__.py

Код этих файлов не включается в сборку. Копии в reference используются только
как локальные справочные материалы. Дистрибутив, модели и текстуры исключены из
индекса: пользователь скачивает их отдельно с исходного адреса.

## Критерий полного переноса

Требование пользователя — редактор для macOS, Windows, Linux с PMM. Текущая
реализация остаётся промежуточным этапом. Сохранение нераспознанных секций PMM
не означает их отображение или редактирование. Для полного переноса нужны:

- Полная точность камеры/света, тени, аксессуары X, звук, фон, экспорт кадров/видео.
- Полная семантика PMX, зависимые кости, SDEF/QDEF, все типы морфов.
- Bullet-совместимая физика и переключатели IK/физики во временных дорожках.
- Toon/sphere/shadow/outline-шейдинг с визуальным сравнением с MMD.
- Полные операции над сценами: создание новых PMM, добавление/удаление моделей,
  редактирование остальных секций и корректные пути при переносе проекта.
- Интерфейс редактора: выделение костей в viewport, манипуляторы, диапазоны ключей,
  диапазоны копирования/вставки и полное управление кривыми интерполяции.
- Проверка отредактированных файлов в оригинальном MMD на Windows и настоящие
  сборки/запуски на всех трёх ОС. Наличие CI-конфига не является такой проверкой.
