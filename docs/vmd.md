# VMD 0002

Чтение и экспорт поддерживают стандартные секции VMD: кости, морфы, камеру,
свет, self-shadow и видимость/переключатели IK. Неизвестные байты после всех
стандартных секций сохраняются при повторном экспорте. Это сохранность данных,
а не обещание воспроизведения всех эффектов.

Камера и свет воспроизводятся в desktop и WebGPU. VMD только с камерой/светом
можно открыть без модели; модель можно добавить позже. Отдельный импорт света
не удаляет ранее загруженную камеру. **Export scene VMD** скачивает или сохраняет
дорожки сцены отдельно от анимации выбранной модели. **Export VMD** сохраняет все
дорожки исходного VMD выбранной модели, включая не вычисляемые пока секции.

Камера использует общую с PMM интерполяцию Bezier по шести каналам. Поле угла
обзора VMD целочисленное: при экспорте дробный FOV округляется. Переключение
perspective — ступенчатое. Прикреплённую к модели/кости PMM-камеру нельзя
представить в VMD без запекания: экспорт такой камеры возвращает ошибку.

Видимость модели и переключатели IK воспроизводятся ступенчато, на кадре ключа.
До первого ключа модель видима и все IK включены. Если ключ не упоминает
конкретную IK-цепь, сохраняется последнее состояние этой цепи. Переключатели
сопоставляются с именами управляющих IK-костей; общий выключатель IK в редакторе
отключает решение всех цепей. Перемотка заново вычисляет состояние из дорожки.
Скрытая модель продолжает вычислять позу, поэтому камера, прикреплённая к её
кости, продолжает двигаться.

Self-shadow пока сохраняется без воспроизведения. Перенос видимости, IK-switch
и self-shadow из VMD в PMM ещё не реализован:
сохранение PMM с такими импортированными данными отклоняется с объяснением;
VMD-экспорт сохраняет их. Нельзя молча объединять разные неизвестные расширения
двух файлов: такой импорт также возвращает ошибку.

Парсер принимает старые файлы, заканчивающиеся на полной границе необязательной
секции. Неполные заголовки/записи, завышенные счётчики, нечисловые значения,
недопустимые флаги и параметры камеры отклоняются. Тесты проверяют отдельно
составленную бинарную сцену, все усечения, порядок координат Bezier и экспорт
всех секций. В браузере проверены импорт камеры без модели и побайтовое
совпадение её экспорта с исходным тестовым файлом.

Структуру секций сверяли с открытым загрузчиком MMD Tools:
https://github.com/MMD-Blender/blender_mmd_tools/blob/main/mmd_tools/core/vmd/__init__.py
Код загрузчика не включён в приложение. Сравнения с воспроизведением исходного
Windows MMD по-прежнему не проводилось.
