01 / ワークスペース

最初のポーズから
次のフレームへ。

テクスチャ付きビューポート、ボーン・モーフ操作、アニメーションタイムライン。使い慣れたツールを、オープンな開発基盤で。

実際のアプリケーション画面
01 / 読み込み

モデルを読み込む。

PMD、または対応範囲内のPMXをテクスチャと一緒に読み込みます。まずは内蔵のデモリグで操作を試せます。

02 / ポーズ

表情とポーズをつくる。

ボーンや表情モーフを調整し、VPDポーズを読み込めます。操作の取り消し・やり直しにも対応。

03 / アニメーション

動きをつける。

VMDモーションを再生し、ボーン・モーフキーを編集。カメラと照明のアニメーションにも追従します。

02 / モデルからシーンへ

シーンに
視点を与える。

モデルより先にカメラ・照明VMDを読み込めます。カメラ追従、表示・IK切り替えの再生、シーンモーションの個別書き出しに対応。

PMM v1/v2の編集機能を拡充中。デスクトップ版ではカメラ・照明キーも編集できます。互換性はまだ一部です。

VMD / VPDモーション / ポーズモーション・シーン軌道

PMM v1 / v2プロジェクト一部編集に対応

ボーン・モーフ軌道、カメラ・照明の再生とキー編集。

アクセサリー、物理、影、全編集設定は未対応。MMDと同一のカメラ挙動は未検証です。元のプロジェクトを保管してください。
WebGPU / WASMブラウザーブラウザー版が動作

ローカルファイル、共通レンダリング・アニメーション、キー編集、書き出し。

WebGPU対応ブラウザーが必要です。高度なカーブとPMMカメラ・照明キーの編集はデスクトップ版のみ。モバイルのGPU対応は端末・ブラウザーによります。
macOS / Windows / Linuxデスクトップ3環境でCI検証

3プラットフォームでビルドと通常テストを実行しています。

デスクトップのGPU再生はmacOSで検証済み。Windows・Linuxの実行時テストは今後の対応です。
