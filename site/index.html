03 / BUILT IN THE OPEN

The model is familiar.
The renderer is new.

A Rust application with an immediate-mode editor and a wgpu rendering backend. The aim is a maintainable foundation for MMD workflows across desktop platforms.

The current renderer is intentionally basic. MMD’s full shading, physics, accessories and complete scene behavior are still ahead.

Look inside the implementation ↗

04 / COMPATIBILITY, CLEARLY

A useful start.
An honest status.

This is an early implementation, not a complete replacement for MikuMikuDance. A file loading successfully does not guarantee identical playback or appearance.

Current file format support and known limitations
Format / systemCurrent supportThe important limits
PMDModelImplemented subset

Mesh, diffuse textures, bones, vertex morphs and basic IK.

Basic shading and approximate IK. No rigid-body physics or complete MMD material behavior.
PMX 2.0 / 2.1ModelPartial

Mesh, four bone influences, skeleton, vertex morphs and diffuse materials.

SDEF/QDEF use linear skinning. Other morph types and advanced bone behavior are not evaluated. Soft bodies are rejected. Details ↗
VMD / VPDMotion / poseBone + morph workflow

VMD bone/morph tracks and VPD bone pose import/export.

VMD camera, light, shadow and IK-switch tracks are not yet part of the motion workflow. VPD has no scene or timeline state.
PMM v1 / v2ProjectPartial project editing

Bone/morph tracks, camera/light playback and keyframe editing.

Camera transforms are approximate; original runtime equivalence is unverified. Accessories, physics, shadows and all original editor settings are not supported. Preserve the original project.
WebGPU / WASMBrowser editorWorking browser build

Local files, shared Rust rendering and animation, key editing and exports.

Recent Chrome/Edge and hardware acceleration required. Files stay in tab memory. PMM camera/light key editing and advanced curve operations remain desktop-only.
Desktop platformsBuild + runtimemacOS development

Rust + wgpu foundations for macOS, Windows and Linux.

Windows and Linux validation is planned. Cross-platform architecture is not a claim that every target has been verified.

Compatibility grows through reproducible tests and real assets. Report a concrete mismatch ↗
